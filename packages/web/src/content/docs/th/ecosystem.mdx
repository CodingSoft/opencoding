ชุดโครงการชุมชนที่สร้างขึ้นบน CodingSoft

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ CodingSoft ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-codingsoft](https://github.com/awesome-codingsoft/awesome-codingsoft) และ [codingsoft.cafe](https://codingsoft.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
