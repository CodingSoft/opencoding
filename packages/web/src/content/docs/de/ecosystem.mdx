Eine Sammlung von Community-Projekten, die auf CodingSoft basieren.

:::note
Möchten Sie Ihr CodingSoft-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-codingsoft](https://github.com/awesome-codingsoft/awesome-codingsoft) und [codingsoft.cafe](https://codingsoft.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
