1. CARACTERÍSTICAS DEL LOGO ORIGINAL:
   • Símbolo: C circular con centro sólido
   • Texto: "CodingSoft" (Coding en negro, Soft en cyan)
   • Colores: Gradiente cyan → azul
   • Estilo: Moderno, limpio, profesional

2. VERSIONES RECOMENDADAS POR USO:
   ┌─────────────┬─────────────────────────────────────┐
   │ Versión     │ Uso Recomendado                     │
   ├─────────────┼─────────────────────────────────────┤
   │ 1           │ Headers de documentación            │
   │ 2           │ Terminal general (80 cols)          │
   │ 3           │ Logs, mensajes rápidas              │
   │ 4           │ Splash screens                      │
   │ 5           │ Banner de bienvenida                │
   │ 6           │ Icono standalone                    │
   │ 7           │ Versión simplificada                │
   │ 8           │ Inline en texto                     │
   │ 9           │ Con colores (terminal moderno)      │
   │ 10          │ Pantalla de inicio                  │
   └─────────────┴─────────────────────────────────────┘

3. COLORES ANSI RECOMENDADOS:
   • Cyan: \x1b[36m (color principal del logo)
   • Blue: \x1b[34m (variante más oscura)
   • Bright Cyan: \x1b[96m (para énfasis)

4. ANCHOS DE TERMINAL:
   • 40 cols: Versión 3, 8
   • 60 cols: Versión 2, 7
   • 80 cols: Versión 1, 5, 9
   • 100+ cols: Versión 4, 6, 10

5. IMPLEMENTACIÓN EN CÓDIGO:

   // TypeScript/JavaScript
   import { logo } from './codingsoft-logo'
   console.log(logo)
   
   // Python
   from codingsoft_logo import logo
   print(logo)
   
   // Go
   import "github.com/codingsoft/ascii"
   fmt.Println(ascii.logo)
