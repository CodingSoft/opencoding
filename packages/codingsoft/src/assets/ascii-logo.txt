[ NOTAS DE USO ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ANCHOS RECOMENDADOS:
   • Versión Compacta (1, 3): 40-60 caracteres
   • Versión Extendida (2, 6, 9): 80 caracteres
   • Versión Bloques (7): 80 caracteres (mejor visualización)

2. CARACTERES UTILIZADOS:
   • Estándar: A-Z, a-z, números, símbolos básicos
   • Bloques Unicode: █, ╔, ╗, ║, ╚, ╝, ═, ░
   • Bordes: ┌, └, │, ├, ┤, ┬, ┴, ┼
   • Flechas/Decoración: ➤, ▸, ◂, ●, ○, ✓

3. COMPATIBILIDAD:
   • macOS/Linux: Todas las versiones
   • Windows CMD: Versiones 1, 3, 5 (ASCII básico)
   • Windows Terminal/PowerShell: Todas las versiones

4. IMPLEMENTACIÓN:
   Para usar en código, simplemente copia la versión deseada
   y guárdala como string o en un archivo .txt
