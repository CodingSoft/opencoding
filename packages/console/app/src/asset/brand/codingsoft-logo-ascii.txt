# ============================================
# COMANDOS PARA MÁXIMA CALIDAD:
# ============================================
#
# Básico (ancho 150):
#   ascii-image-converter --width=150 logo.png
#
# Con color:
#   ascii-image-converter --color --width=150 logo.png
#
# Máxima calidad (braille - más detalle):
#   ascii-image-converter --braille --width=200 logo.png
#
# Braille con color:
#   ascii-image-converter --braille --color --width=200 logo.png
#
# Caracteres personalizados:
#   ascii-image-converter --map=" .:-=+*#:@" --width=150 logo.png
#
# Dimensiones específicas:
#   ascii-image-converter --dimensions=200,100 logo.png
#
# Guardar en archivo:
#   ascii-image-converter --width=150 logo.png > codingsoft-ascii.txt
#
# Usando el script personalizado:
#   bun packages/script/codingsoft-logo-ascii.ts logo.png --color --width=200
#   bun packages/script/codingsoft-logo-ascii.ts logo.png --braille
#   bun packages/script/codingsoft-logo-ascii.ts logo.png --output=codingsoft.txt
#
# ============================================

# ============================================
# NOTA:
# Para convertir el logo real, coloca la imagen "1.png" o "logo.png"
# en el directorio del proyecto y ejecuta:
#   ascii-image-converter --braille --color --width=200 1.png
